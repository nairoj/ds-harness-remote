# 浏览器缓存

缓存仅保存在当前浏览器，不在中继服务器上保存明文会话。

## 资源

原生插件使用 `/native/versions/<内容版本>/plugins/…` 路径，版本由插件内容摘要生成。生产环境 Service Worker 只缓存构建清单中的原生静态资源，按内容版本命中；不会缓存登录、API、WebSocket、HTML 页面或 RPC 响应。资源更新时启用新缓存并清理旧资源缓存。

## 目录、自动连接与会话位置

- 目录缓存按账号、电脑设备 ID 和电脑身份公钥隔离。
- 打开页面或登录成功后，若上次连接的电脑在线且身份公钥已受信任，则自动建立加密连接并进入原生工作区；点击顶栏“切换电脑”时清除自动连接记录并回到设备列表。
- 连接同一电脑时，原生页面先立即取得本地目录（0ms），优先打开当前会话并在后台顺序预热最多 4 个最近会话（`PREWARM_SESSIONS`），预热完成后再发起后台完整目录更新；对最近访问的最多 8 个会话（`MAX_RETAINED_SESSIONS`）通过 `ctx.sessions.retain(id, { source: "webCache" })` 保持内存引用，使会话间切换无需重复拉取历史。
- 目录只持久化导航字段和标题。运行标记、Agent 可用性、审批、通知和其余详情投影不持久化。
- 不缓存或单独渲染历史消息正文预览层，直接进入真实原生 DSH 界面并由原生会话流加载当前会话。
- 恢复该电脑上最后查看的会话（最近 10 个访问会话保留阅读位置）。记录阅读锚点、相对位置、是否跟随底部及已加载窗口起点；必要时按原生历史接口加载到保存窗口，再恢复滚动。
- 当前运行状态和审批只来自重新建立的原生实时连接，不使用缓存恢复控制状态。

退出登录时关闭缓存写入者、断开连接并清理所有本应用目录/位置缓存、自动连接记录与资源缓存。同源其他打开页面收到退出通知也会断开，避免旧页面重新写入缓存。缓存损坏或浏览器存储不可用时，仍可使用实时连接。

第一次没有缓存仍需完整下载目录；此功能改善再次连接的等待体验，没有减少电脑端目录接口返回量。手机 Safari 实机体验仍需用户验证。
