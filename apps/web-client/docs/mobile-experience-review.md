2026-10-27，实际操作公网 `https://47.102.38.163:5555`，仅连接 HIH-D-23754。Chrome 触控模拟，390×844 与 320×844；不是实际 iPhone Safari。独立临时浏览器上下文，无 trace/HAR，凭据仅内存读取。

仅查看 `.private/test-sessions.json` 中的专用验收会话，没有发送消息、修改现有会话、审批、部署或重启服务。测试脚本与截图在 `.private/mobile-review/`，不进入 Git。

## 主要反馈

| 优先级 | 观察 | 复现与影响 | 建议 |
|---|---|---|---|
| 高 | 缓存预览暴露原生界面隐藏的工作区指令 | 打开专用测试会话、等待缓存建立、刷新并连接同一电脑。缓存层把 `<system-reminder>` 及 AGENTS 内容作为“你”的消息展示，正常原生历史没有这一大段内容。390px 下第一屏几乎被指令占满，需要大量滚动才能找回正常对话。证据：06-cache-preview.png，与05-history.png对比 | 预览消息采用与原生历史相同的可见性规则，排除内部注入内容；这是展示一致性问题，不应简单截短所有用户消息 |
| 中 | 缓存预览和原生历史是两套阅读布局 | 预览占据整个工作区，只提供“查看实时页面”；没有目录或输入区。实时页面出现后切换到气泡布局。预览是只读等待界面，并不能立即继续输入。证据：06-cache-preview.png | 明确只读预览状态；进一步评估是否在同一会话布局内展示缓存，减少跳变 |
| 中 | 窄屏阅读空间和触控目标偏小 | 320px下仍常驻约55px图标栏；顶栏约60px，后台更新提示两行约58px。模型选择器收缩到约46px宽，只剩图标与下拉，当前模型不可见；多数消息/工具按钮28×28px，左栏36×36px。证据：08-width-320.png、results.json | 手机收纳次要工具，扩大主要触控区域，模型选择至少保留可辨识的短名 |
| 中 | 首次进入仍明显等待，且刷新需重新选择设备 | 本次首次连接约74.3秒才出现测试历史与目录；独立前次约77.2秒。刷新保留登录，但仍回到设备列表，用户需再次点电脑。已有缓存后速度改善明显 | 先保留明确状态；是否自动连接上次设备属于行为选择，应由用户决定 |

## 已验证有效的部分

| 流程 | 本次观察 |
|---|---|
| 手机登录、设备选择、首次信任 | 390px正常显示并可点按，信任弹窗未越界；没有在截图中保存密码 |
| 冷启动 | 外层连接约5.8秒可见，但当时原生页面仍处于 Loading plugins；完整历史和目录约74.3秒可读。不能将外层出现等同于可聊天 |
| 刷新缓存 | 重新点同一电脑后约221ms显示缓存预览，约7.46秒出现实时历史；没有等待全量目录完成 |
| 当前会话恢复 | 自动回到专用验收会话，包含 WEB_CLIENT_OK 的历史；无需从目录重新寻找 |
| 滚动保存 | 在390×500视口滚动后，缓存记录scrollTop=25、tail=false及消息锚点。本轮随后改变视口高度，因此不作为同尺寸精确滚动恢复验收 |
| 状态提示 | 实时页面上方明确写着“已显示本地目录，后台正在更新。运行状态和审批以电脑实时确认为准。”；不会把缓存文字当成新的审批操作入口 |
| 窄屏布局 | 390与320px的原生文档scrollWidth均等于视口宽，无文档级横向溢出；正常消息可读，输入区可见 |
| 退出登录 | 独立测试浏览器的dsh-web-cache-*本地项及dsh-resources-*资源缓存均清空；未影响用户浏览器 |
| 浏览器错误 | 本轮未捕获pageerror |

## 未能据此确认的项目

- 真机Safari、地址栏收缩、安全区、软键盘遮挡和中文输入法：Chrome尺寸/触控模拟不能替代实机。
- 精确滚动恢复：本轮验证保存、会话恢复和历史恢复，但改变视口后未作锚点位置误差断言。
- 完整断线重连：模拟浏览器离线5秒后历史仍可读；该操作不保证已存在的WebSocket真的断开，因此不把它算作断线恢复成功或失败。证据10-offline.png仅证明这5秒的页面状态。
- 消息、审批不自动重放：本轮只读体验，没有制造运行中或待审批状态，不据此声称验证通过。
- 账号/电脑交叉隔离：本轮只有一个账号和一个授权Host，未创建额外身份验证隔离。
- 侧栏菜单深度操作：本轮原生界面为中文，英文侧栏定位未匹配，未继续点击展开，不声称已评估完整菜单。
