## 测试推进

1. 先建立最小加密客户端并在当前本地 Host 上执行只读冒烟。
2. 接入匹配版本的原生页面，执行浏览器端到端测试。
3. 对竞态、超时和断线写针对性的自动化回归；不以静态字符串断言替代行为验证。
4. 测试报告逐项记录已通过、失败和未验证，不把模拟移动端当成真实 iPhone 验证。
